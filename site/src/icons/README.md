# Icons

Brand marks come from [svgl](https://svgl.app), vendored rather than
fetched, so the build needs no network and the file cannot change
under the site.

- `github.svg` — the GitHub mark, from `svgl.app/library/github_light.svg`.
  The fill is rewritten to `currentColor` so one file serves both
  themes, and the size is `1em` so it takes the type size around it.
  GitHub's marks are GitHub's; see <https://brand.github.com>.
